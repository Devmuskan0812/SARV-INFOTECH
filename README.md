## 🚀 Projects Overview

### 1. Calculator
A responsive web calculator built using HTML, CSS, and JavaScript.
- **Features:**
  - Standard arithmetic calculations (addition, subtraction, multiplication, division).
  - Clear (`C`) and Delete (`DEL`) controls.
  - Interactive grid design with sleek styling.

### 2. Tribute Page
A futurist tribute web page dedicated to **Steve Jobs** (1955 – 2011).
- **Features:**
  - Modern, responsive typography and sleek dark layout.
  - Key breakthrough timeline cards from 1976 to 2010.
  - Inspiring quotes and reference links.
